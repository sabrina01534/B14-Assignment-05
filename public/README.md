#Development Stack


##Description

This is React-based application where users can explore different web development techonologies and build their own stack.

##Techonologies which are used:
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- Vite
- JSON data

##Features:

1.Users can see different techonology like React,TypeScript,JavaScript and more.

2.User can click "Add to Stack" button to add a technology to their stack.

3.Users can remove a techonology or remove all selected techonologies by pressing "Remove All" button.

1.JSX is Syntac which write HTML-like code inside JavaScript or TypeScript.React use this to make UI code easier and understand.

2.Props passed data from parent to child componenet.State is a data which is belong to a component and can change when user interacts.

3.useState allows us to create and update changing data in a React component.I used it to select techonology by user.

4.useEffect is used to perform a task after a component renders.Ineed it to load json data but didn't use it in my project.

5.React uses the key to identify each item in a list. It helps React understand which item has changed, been added, or removed.

6.Conditional rendering means showing different content depending on a condition.I used it at "Add to stack" button.

7.I pass data from a parent component to a child component by using props.A child can send information back to the parent by calling a function passed through props.
